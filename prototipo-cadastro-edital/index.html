Configuração de Edital
Catálogos, modelos e wizard para cadastro de edital de processo seletivo.
  1. Início

O que você quer fazer?

Este protótipo demonstra o fluxo de cadastro de edital com 13 passos, alimentado por catálogos editáveis (incluindo obrigatoriedades legais que substituem regras hardcoded). Os dados ficam no localStorage do navegador.

Editais

Criar novo edital pelo wizard, ver rascunhos e editais publicados.

—

Modelos de edital

Templates reutilizáveis. Crie um edital, salve como modelo, e use-o como ponto de partida para outros do mesmo tipo.

—

Catálogos

Tipos de edital, modalidades, tipos de etapa, locais, documentos, critérios de desempate e obrigatoriedades legais.

—

Sobre o protótipo

  • Sem backend. Todo o estado vive no localStorage do navegador.
  • Tema gov.br DS. Acessibilidade WCAG 2.1 AA / e-MAG 3.1 obrigatória (autarquia federal).
  • Validação dinâmica. Regras de obrigatoriedade são dado, não código — atualizáveis sem deploy.
  • RN08. Ao publicar, o edital congela um snapshot JSON com hash sha256.
